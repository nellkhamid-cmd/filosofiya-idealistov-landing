# Лендинг «Философия идеалистов на Жуковского»

Статичный сайт без сборки. Открыть `index.html` через любой веб-сервер
(для проверки: `python -m http.server 8765` в этой папке → http://localhost:8765).

Контент, порядок блоков и изображения — как в макете (`Desktop_1200(1160).pdf`, `Mobile_320(300).pdf`).
Изменён только дизайн, вёрстка и анимации.

## Структура
- `index.html` — разметка, 12 блоков в порядке макета + шапка и поп-ап квиза.
- `assets/css/style.css` — стили, mobile first (брейкпоинты 480 / 768 / 1024 / 1280 / 1600).
- `assets/js/main.js` — анимации, карусели, табы, карта, форма, лайтбокс, кнопки квиза.
- `assets/js/vendor/` — GSAP 3.13 + ScrollTrigger; SplitText и Lenis подгружаются только на десктопе с мышью.
- `assets/fonts/` — Manrope (вариативный 200–800, woff2: кириллица, латиница, ₽).
- `assets/img/` — рендеры в webp (несколько ширин + отдельные кадры для телефона), `map.svg`, фавиконки, `og.jpg`.

## Анимации
Приёмы с сайта LUCE (`сайты дизайны/luce-design-system`):
- первый экран появляется на CSS сразу с первой отрисовкой (без прелоадера — быстрее LCP);
- первый экран на десктопе «прилипает», следующий блок наезжает шторкой, фото темнеет и наезжает;
- «раскрытие» фото в блоке «О проекте» (рамка растёт до краёв, фото отъезжает — встречные масштабы, только transform);
- подчёркивание смысловых слов, когда они доходят до середины экрана;
- «Преимущества» на десктопе: экран прилипает, карточки едут горизонтально от вертикального скролла (стрелки тоже работают);
- «Предчистовая отделка» на десктопе: pin + проявление плашки White Box;
- заголовки выезжают строками из-под маски, блоки появляются лесенкой, счётчики цифр.

Интерфейс (скилл ui-motion): «жидкий» индикатор табов планировок, смена панелей с размытием,
кнопка отправки нижней формы → лоадер → галочка + тост. Пружины на CSS `linear()`.

Производительность: анимируются только `transform`/`opacity`, без blur-подложек на крупных слоях;
анимации прокрутки создаются порциями после первой отрисовки; на телефоне нет pin, Lenis, SplitText
и scrub-эффектов на больших фото. Фото — AVIF с запасным webp.

На десктопе каждый блок помещается в высоту окна (проверено 1366×768 … 1920×1080).

На телефоне нет закреплений экрана (pin) — только скролл-анимации, карусели свайпаются нативно.
`prefers-reduced-motion` учитывается: анимации и прелоадер отключаются, всё видно сразу.

## Квиз, форма и аналитика
В конце `index.html`, блок `window.FI_CONFIG`:
- `marquizId` — id квиза Марквиз. Все кнопки-призывы помечены атрибутом `data-quiz` и вызывают
  `Marquiz.showModal(marquizId)`. Своей всплывающей формы нет. Код подключения Марквиза вставить перед `</body>`.
- `leadEndpoint` — адрес обработчика нижней формы «Подберем варианты…» (POST, JSON). Пока пусто — заявка пишется в консоль браузера.
- `metrikaId` — номер счётчика Яндекс.Метрики. Цели: атрибут `data-goal` на кнопках
  (`hero_consult`, `buy_mortgage`, `plan_1k`, …), отправка нижней формы — `lead_final`.

Из нижней формы уходят: имя, телефон, комнатность, UTM и yclid, адрес страницы.
